argument-hint: [ชื่อ event + ช่วงเวลา เช่น "Halloween 25-31 ต.ค. ล่าฟักทอง", "Double EXP ทุกเสาร์ 20:00"]

Event: **$ARGUMENTS**

1. ออกแบบสั้น ๆ: กติกา, เวลา (เขตเวลา Asia/Bangkok), รางวัล, กันโกง (จำกัดต่อ account/IP-GEPARD ถ้ามี, cooldown), ผลต่อเศรษฐกิจ
2. สร้าง `npc/custom/events/<ชื่อ>.txt` ใช้ `OnClock`, `OnDay`, `OnMinute`, `gettime()` ควบคุมเปิด/ปิดอัตโนมัติ, ประกาศ `announce` สีสวย ก่อนเริ่ม 10/5/1 นาที
3. ใส่ตัวแปรเปิด/ปิด ให้ GM สั่งได้ (`@eventctl <ชื่อ> on|off`) และบันทึกผู้ชนะลง SQL (ตาราง `rae_event_log`) เพื่อให้เว็บไซต์ดึงไปแสดง
4. ถ้าใช้ item/monster/map ใหม่ ให้ทำครบทั้ง db และไฟล์ client ตาม `/ro-system`
5. เขียนข่าวประกาศภาษาไทย 1 ชิ้น (หัวข้อ, รายละเอียด, รางวัล, เวลา) สำหรับเว็บไซต์/Discord
6. TIS-620, compile/โหลดผ่าน, วิธีทดสอบ (ใช้ตัวแปรบังคับเวลาเพื่อทดสอบได้ทันที)
