บัคที่แจ้ง: **$ARGUMENTS**

1. ถามข้อมูลที่ขาดเพียงข้อเดียวถ้าจำเป็นจริง ๆ (เช่น ข้อความ error จาก map-server) ไม่งั้นเริ่มเลย
2. หาให้เจอว่าเกิดจากไฟล์ไหน (script / C++ / db yml / conf / ฝั่ง client) — อธิบายสาเหตุเป็นภาษาไทยง่าย ๆ
3. ถ้าเป็นปัญหาฝั่ง client (ชื่อ item เป็น ???, icon หาย, ข้อความไทยเพี้ยน, sprite ไม่ขึ้น) ให้บอกไฟล์ใน client ที่ต้องแก้ (`System/itemInfo*.lub`, `data/luafiles514/...`, `data/texture/...`) และตัวอย่างโค้ด lua ที่ต้องเพิ่ม
4. แก้แบบ diff เล็กที่สุด ยึดกฎ encoding TIS-620 ใน CLAUDE.md
5. Compile และเช็ก log การโหลด NPC/DB
6. สรุป: สาเหตุ, ไฟล์ที่แก้, ขั้นตอนทดสอบในเกม (คำสั่ง @ ที่ต้องใช้), ความเสี่ยงที่อาจกระทบระบบอื่น
