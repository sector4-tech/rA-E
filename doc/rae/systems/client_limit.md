# จำกัดจำนวน Client ต่อเครื่อง (ต่อ IP)

## ทำงานอย่างไร
- map-server จะนับว่า IP เดียวกันมีตัวละครอยู่ในเกมกี่ตัว ทุกครั้งที่มีตัวละครเข้าเกม (`src/map/client_limit.cpp`)
- ถ้ามีเกิน `max_clients_per_ip` (ค่าเริ่มต้น 5) **ตัวละครที่เพิ่งเข้ามา** จะได้รับข้อความเตือน
  ขยับตัวไม่ได้ และถูกตัดการเชื่อมต่อหลัง `max_clients_kick_delay` ms (ค่าเริ่มต้น 5 วินาที) จึงเหลืออยู่ในเกม 5 ตัวเสมอ
- ไม่นับร้านค้าออฟไลน์ (@autotrade) และไม่จำกัด GM (กลุ่มที่มี Level 1 ขึ้นไป)
- ตั้งค่าได้ที่ `conf/battle/feature.conf` (ใส่ `0` = ไม่จำกัด)

## ข้อจำกัดที่ต้องรู้
เซิร์ฟเวอร์ **มองเห็นได้แค่ IP** ไม่เห็นว่าเป็นคอมพิวเตอร์เครื่องไหน
- **ร้านเกม / หอพัก / บ้านที่ใช้เน็ตร่วมกัน**: ทุกเครื่องจะออกเน็ตด้วย IP เดียวกัน จึงถูกนับรวมกัน
  ให้เพิ่ม IP ของสถานที่นั้นเข้า whitelist ด้วยคำสั่ง GM:
  - `@clwhite` ดูรายการ
  - `@clwhite add 203.0.113.10` เพิ่ม IP / `@clwhite del 203.0.113.10` ลบ IP
  - `@clwhite me` เพิ่ม IP ที่ตัวคุณใช้อยู่ตอนนี้
- **คนที่ใช้ VPN หรือเน็ตมือถือหลายเครื่อง** จะได้ IP คนละตัว จึงหลบระบบนี้ได้
- ถ้าต้องการจำกัดตามเครื่องจริง (Hardware ID) ต้องใช้โปรแกรมป้องกันฝั่ง client เช่น GEPARD Shield
  (มีค่าใช้จ่าย อยู่ใน ROADMAP Phase 1)

## ทดสอบ
1. ตั้ง `max_clients_per_ip: 2` ชั่วคราว แล้วรีสตาร์ท map-server
2. เปิด client 3 หน้าต่างจากเครื่องเดียวกัน แล้วล็อกอินด้วย 3 ไอดี (ไอดีที่ไม่ใช่ GM)
3. ตัวที่ 3 ต้องได้ข้อความเตือนสีเหลือง และหลุดออกจากเกมหลัง 5 วินาที ส่วน log ของ map-server จะขึ้น `client_limit: ... kicked`
4. พิมพ์ `@clwhite me` ด้วยไอดี GM แล้วลองเข้าตัวที่ 3 อีกครั้ง ครั้งนี้ต้องเข้าเกมได้
